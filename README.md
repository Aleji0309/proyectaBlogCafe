
# Blog Café - Udemy Course Project  

## Description  
This project was developed as part of a **Front-End course on Udemy**. It is a **modern and responsive blog** focused on coffee culture, built using **HTML and CSS**.  

The goal of this project was to practice **semantic HTML, CSS layouts, and responsive design**, ensuring a smooth user experience across different devices.
