**Blog Café** is a static blog-style landing page built with **HTML** and **CSS**, focused on clean layout, visual consistency, and responsive design. It simulates a coffee-related blog with articles, imagery, and a modern design.

## 🌐 Live Preview

- 🔗 **Live Website**: [https://proyectablogcafe.netlify.app](https://proyectablogcafe.netlify.app)  
- 📁 **GitHub Repository**: [https://github.com/Aleji0309/proyectaBlogCafe](https://github.com/Aleji0309/proyectaBlogCafe)

## 🛠️ Technologies Used

- **HTML5** – Semantic content structure  
- **CSS3** – Custom layout, styling, and media queries  
- **Netlify** – For deployment and live hosting

## 📋 Project Description

This blog-style landing page is designed to display articles, categories, and highlights related to coffee culture. It includes:

- Hero banner with overlay text  
- Grid-based article layout  
- Sidebar with categories or about section  
- Call-to-action in the footer

This project was created to practice multi-section design, semantic HTML, responsive layout, and consistent typography—all without JavaScript.

## 📌 Key Features

- Static, responsive blog layout  
- Mobile-first design using CSS Grid and Flexbox  
- Image cards with content previews  
- Clean navigation and footer  
- Modern and cozy aesthetic

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaBlogCafe.git
````

2. Navigate to the folder:

```bash
cd proyectaBlogCafe
```

3. Open `index.html` in your browser.

> No installation needed — this is a 100% static project.
